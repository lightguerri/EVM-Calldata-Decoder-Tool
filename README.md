## What This Tool Does

- Decode EVM calldata from any transaction
- Detect function signatures and method IDs
- Parse function parameters with correct types
- Support for all EVM-compatible chains
- Load custom ABI for contract decoding
- Visualize decoded data in table and tree views
- Export decoded data to JSON
- Batch decode multiple transactions
- Works on Windows 10 and Windows 11

EVM Calldata Decoder is a professional tool for developers and auditors who need to understand transaction calldata. It provides automatic function detection, parameter parsing and ABI support for complete decoding. This is a fully functional application with no limitations.
